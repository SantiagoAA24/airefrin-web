Etiqueta pequeña en píldora, en mayúsculas, 12px y peso 800.

- **Acento (naranja):** marca lo nuevo, por ejemplo «Nuevo». Texto `navy-950`; el blanco no cumple contraste sobre este naranja.
- **`tone="ok"`:** estado correcto, por ejemplo «Revisado» en la ficha de visita.

No usar más de una etiqueta por tarjeta ni para llamar a la acción.
