El botón siempre es una píldora (`radius-pill`) con texto `button` (16px, 700).

| Variante | Uso | Fondo y texto |
| --- | --- | --- |
| `primary` | Una acción principal por pantalla: Solicitar cotización | `gradient-cta` + blanco |
| `outline` | Acción secundaria sobre fondo claro | borde y texto `blue-600` |
| `outline-light` | Acción secundaria sobre navy | borde `cyan-400`, texto blanco |
| `whatsapp` | Escribir por WhatsApp o cotizar por WhatsApp | `green-700` + blanco |
| `accent` | Uso puntual, nunca junto a `primary` | `orange-500` + `navy-950` |

`arrow` añade la flecha al final. `size="sm"` se usa dentro de tarjetas y en el header. Nunca poner texto blanco sobre `orange-500` ni `cyan-400`.

Cada pantalla combina como máximo un `primary` y un secundario. Foco visible: anillo de 3px `cyan-400` con desplazamiento de 3px.
