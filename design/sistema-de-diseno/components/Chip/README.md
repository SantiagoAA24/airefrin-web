Chip de selección en píldora, para filtros (marca) y opciones cortas (área del espacio, exposición). Usa `aria-pressed`: seleccionado es `blue-600` relleno con texto blanco; sin seleccionar es blanco con borde `border-control`.

Alto mínimo 46px para dedos. Agrupar en un contenedor con `role="group"` y una etiqueta visible encima. No usar para navegar entre páginas.
