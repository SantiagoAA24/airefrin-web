Iconos de trazo (stroke) de 24px con terminaciones redondeadas, en `currentColor`. El grosor es 1.8 por defecto; 1.5–1.6 cuando el icono se muestra grande (48–52px) y 2–2.4 dentro de botones y pasos.

**Cuándo usarlo:** en tarjetas de servicio, cifras, sectores y pasos del proceso. Un icono nunca va solo: lleva siempre un texto al lado.

**Color:** `blue-600` sobre fondos claros, `cyan-400` sobre navy y blanco sobre superficies de color. No usar `cyan-brand`.

El catálogo incluye los 19 iconos que usa la página de inicio. Para uno nuevo se mantiene el mismo trazo y se agrega a este componente, no se mezclan librerías.
